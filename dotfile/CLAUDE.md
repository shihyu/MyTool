# Claude Code 指令

## 必須遵守（TDD 流程）
- **先寫測試，再寫實作**（Red-Green-Refactor）
- 務必測試所有程式碼，包含邊界條件和錯誤情況
- 修改檔案時明確說明修改的檔案名稱
- 遇到 bug 時主動加入 debug log 分析問題

## TDD 具體要求
- 每個功能先寫 failing test
- 實作最小可行代碼讓測試通過
- 通過後進行重構
- 測試覆蓋率要包含正常、邊界、錯誤情況

## 編碼風格
- 變數命名：使用有意義的英文名稱
- 錯誤處理：必須包含適當的錯誤訊息
- 註解：複雜邏輯必須加註解

## 禁止行為
- 不要先寫實作再補測試
- 不要給未測試的程式碼
- 不要過度設計（避免 over-engineering）
