# Claude Code 指令

## 必須遵守（TDD 流程）
- **TDD：先寫測試，再寫實作**（Red-Green-Refactor）
- 務必測試所有程式碼，包含邊界條件和錯誤情況
- 修改檔案時明確說明修改的檔案名稱
- 遇到 bug 時主動加入 debug log 分析問題

## 代碼品質
- 變數命名：使用有意義的英文名稱
- 驗證所有外部輸入，防止注入攻擊
- 考慮性能：避免 N+1 查詢、迴圈中的 I/O 操作
- 錯誤處理：包含適當的錯誤訊息和恢復機制

## Git 工作流
- commit 訊息要清楚描述改動
- 每個功能用獨立的 commit
- 大重構要分步驟進行

## 安全性
- 不要在程式碼中寫死密碼或 API key
- 使用 prepared statement 防止 SQL 注入
- API 回應時間超過 500ms 要優化

## 禁止行為
- 不要先寫實作再補測試
- 不要給未測試的程式碼
- 不要過度設計（避免 over-engineering）
- 不要在迴圈中做資料庫查詢
